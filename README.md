# Qualitative and Quantitative Analysis of 5G Standalone Cores

This project presents a structured qualitative and quantitative comparison of three open-source 5G Standalone Core implementations: Open5GS, free5GC, and OpenAirInterface (OAI) 5GC. It evaluates their functional capabilities, deployment characteristics, control-plane and user-plane performance, scalability, and operational stability. The study combines systematic testing, multi-UE load evaluation, performance measurements, and protocol-level analysis to examine the behaviour of each implementation under different experimental conditions. It identifies the capabilities, strengths, limitations, and practical differences among the three platforms. The project consolidates the experimental methodology, research findings, comparative analysis, and supporting evaluation artefacts into a comprehensive technical study.
